# 🤖 FAQ Chatbot

An AI-powered FAQ Chatbot developed using Python, Streamlit and Natural Language Processing as part of the CodeAlpha Artificial Intelligence Internship.

## 📌 Project Description

This chatbot answers frequently asked questions related to Python, Artificial Intelligence and programming using text similarity techniques.

## ✨ Features

* Simple and interactive chatbot interface.
* Answers predefined frequently asked questions.
* Text preprocessing.
* TF-IDF vectorization.
* Cosine similarity for matching questions.
* Displays the most relevant answer.

## 🛠️ Technologies Used

* Python
* Streamlit
* Scikit-learn
* NLTK
* TF-IDF
* Cosine Similarity
